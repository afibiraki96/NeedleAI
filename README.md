# NeedleAI 🤖
**FM Ticket Classification Agent — 2026 JLL Hackathon**

## What is NeedleAI?
An AI-powered agent that automatically reads, validates, and corrects 
facilities management ticket classifications in real time.

## The Problem
~20% of FM tickets are miscategorized — causing misrouting, SLA failures, 
and missed scope revenue opportunities.

## The Solution
Claude AI reads each ticket description and validates the Sub-Category 
and Level 2 against the actual content. Wrong tickets get corrected 
instantly. Root causes get surfaced. Teams get retrained. Scope gaps 
get flagged.

## Results
- ✅ Tested on 2,047 real FM tickets
- ✅ ~20% misclassification rate identified
- ❌ Manual process: FAILED
- ✅ Claude AI: PASSED

## Tech Stack
- Claude AI / JLL GPT
- React (dashboard)
- Python (data pipeline)
- Real JLL FM ticket data
